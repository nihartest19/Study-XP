# Study XP – Development Log

## Project Overview

Study XP is a gamified study productivity web application designed to make studying more engaging. Users can create tasks, complete them, earn XP (experience points), level up, and track progress over time.

The goal of the project was to combine productivity and gaming concepts into a simple system that encourages consistency and motivation.

---

## AI Coding Assistant Used

* ChatGPT → Used for brainstorming, planning, refining ideas, debugging discussion, feature design, and improving project logic.
* Replit AI → Used to generate and build the actual working application and assist with implementation.

---

## AI Model Used

* ChatGPT (model-> GPT 5.5)
* Replit Agent 4

---

## Important Prompts Given

Some of the major prompts used during development:

* Build a gamified study tracker website with XP and level progression.
* Create a system where completed tasks increase user XP.
* Store user progress so data persists between sessions.
* Fix progress syncing and prevent users from seeing mixed progress.
* Improve fairness of the XP reward system.
* Add persistent database-based storage instead of relying only on browser storage.
* Help structure GitHub repository and deployment process.

---

## Code Generated by AI

Most of the project implementation was generated with AI assistance, including:

* Project structure and setup
* Frontend UI and styling
* Task management functionality
* XP and leveling system
* Progress tracking logic
* Database integration
* Deployment guidance
* General debugging support

AI accelerated development and allowed rapid iteration of features.

---

## Manual Modifications Made

The following changes and decisions were made manually:

* Reviewed generated outputs and selected final project direction.
* Adjusted and refined project requirements.
* Improved game balance for XP progression.
* Identified fairness issues where users could manually assign high XP values.
* Considered replacing variable XP rewards with fixed XP rules.
* Tested project behavior across sessions and devices.
* Managed GitHub repository setup, commits, screenshots, and publishing workflow.
* Performed manual debugging and feature validation.

---

## Challenges Faced

During development, several challenges appeared:

* Understanding where and how user data was stored.
* Progress persistence and identifying browser-based limitations.
* Preventing progress from mixing across users.
* Designing a fair XP system that cannot be exploited.
* Publishing and updating the live version correctly.
* Organizing GitHub documentation and repository structure.
* Converting an AI-generated prototype into a usable working application.

---

## Lessons Learned

* AI can significantly speed up development but still requires human decisions.
* Generated code should always be reviewed and tested.
* Data storage design matters more than UI for real applications.
* Fair game mechanics are important for user trust.
* GitHub documentation improves project quality and presentation.
* Building an MVP quickly allows faster improvement cycles.
